# Gestión de Alumnos y Materias (Android + Supabase)

Aplicación nativa para Android desarrollada en **Kotlin** con vistas clásicas (**XML**), diseñada para consumir datos desde una base de datos PostgreSQL alojada en **Supabase**. 

Este proyecto es el resultado de las prácticas de laboratorio de la **Universidad Técnica Estatal de Quevedo (UTEQ)** para las asignaturas de *Aplicaciones Móviles* y *Sistemas Móviles y Ubicuos*.

## Características Principales

*   **Menú Principal Institucional**: Interfaz con los colores corporativos de la UTEQ que permite la navegación fluida entre módulos.
*   **Módulo de Alumnos**: Consulta asíncrona a Supabase para recuperar un listado de estudiantes, mostrándolos en un `ListView` con un adaptador personalizado (`AlumnoAdapter`).
*   **Módulo de Materias (Selectores Dependientes)**: Uso de `ExposedDropdownMenu` (Material Design). Al seleccionar un nivel o semestre (datos locales en `strings.xml`), se dispara una consulta filtrada a Supabase para cargar dinámicamente las materias correspondientes a ese nivel en un segundo menú desplegable.
*   **Manejo de Errores Global**: Implementación de `SupabaseErrorHandler` para capturar excepciones REST y mostrarlas al usuario mediante diálogos de Material Design.

## Stack Tecnológico

*   **Lenguaje**: Kotlin 2.2+
*   **Interfaz de Usuario**: XML (Views tradicionales, AppCompat, Material Components).
*   **Backend as a Service (BaaS)**: [Supabase](https://supabase.com/) (PostgreSQL).
*   **SDK Supabase para Kotlin**: `io.github.jan-tennert.supabase:postgrest-kt:3.6.0`.
*   **Cliente HTTP**: Ktor (`ktor-client-android`).
*   **Programación Asíncrona**: Coroutines (`lifecycleScope.launch`).

## ⚙️ Configuración del Proyecto (¡Importante para clonar!)

Para proteger las credenciales, este proyecto utiliza el archivo `local.properties` (el cual está excluido en el `.gitignore`). Si clonas este repositorio, **debes configurar tus propias credenciales** antes de compilar.

1. Abre el proyecto en Android Studio.
2. En la raíz del proyecto, busca o crea el archivo `local.properties`.
3. Añade las siguientes líneas con los datos de tu proyecto de Supabase (sin comillas):

```properties
SUPABASE_URL=https://TU_ID_DE_PROYECTO.supabase.co
SUPABASE_KEY=TU_CLAVE_ANON_PUBLICABLE
```

## Esquema de Base de Datos (Supabase)

Para que la aplicación funcione, debes tener las siguientes tablas en el SQL Editor de tu proyecto en Supabase, además de habilitar RLS (Row Level Security):

### Tabla: `alumnos`

```sql
CREATE TABLE public.alumnos (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    nombres TEXT NOT NULL,
    paralelo VARCHAR(1) NOT NULL,
    correo TEXT UNIQUE NULL,
    telefono VARCHAR(15) NULL,
    foto TEXT NULL
);

ALTER TABLE public.alumnos ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Permitir lectura alumnos" ON public.alumnos FOR SELECT TO anon USING (true);
```

### Tabla: `materias`

```sql
CREATE TABLE public.materias (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    nombre TEXT NOT NULL,
    nivel INT NOT NULL
);

ALTER TABLE public.materias ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Permitir lectura materias" ON public.materias FOR SELECT TO anon USING (true);
```
